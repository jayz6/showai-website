# showai-website

Landing page for [ShowAI](https://github.com/jayz6/showai-releases) — static HTML/CSS/JS, no build step, no dependencies.

- `index.html`, `styles.css`, `script.js`, `assets/` (icon generated by the app repo's `scripts/icon/make-icon.swift`)
- Hosted free on **GitHub Pages** from the `main` branch of this repo.
- Downloads and the install script come from the public releases repo (`jayz6/showai-releases`).

Preview locally: `python3 -m http.server 8000` → http://localhost:8000
